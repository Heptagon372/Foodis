## 2. 디자인 토큰 — `app/globals.css` `@theme`

Tailwind v4 토큰으로 정의 → `bg-mint-500`, `text-green-800`, `text-caption` 처럼 바로 쓴다.

- 컬러: `mint-500/600/100` · `green-800` · `ivory` · `surface` · `charcoal` · `muted` · `line` · `diet-ok/warn/no/unknown`
- 국가 Accent: DB `countries.accent_color` → `accentBg()` (FoodCard.tsx) 가 그라데이션 생성. **사진이 없어도 카드의 주인공은 그 나라 색**
- 글꼴: `font-display` = Fraunces(워드마크·제목), 본문 = Pretendard → Inter. 두 스택 맨 앞에 국기 글꼴(§4)
- 타입: `text-h1`(28) · `text-h2`(22) · `text-subtitle`(18, 음성 자막) · `text-caption`(13)
- 모션: `animate-pulse-ring`(음성 버튼만 상시) · `animate-wave` · `animate-spin-slow` · `animate-rise`(200ms) · `animate-sheet`(240ms). 인트로 외 300ms 초과 없음

## 4. 설계 중 내린 결정

1. **Windows 국기 깨짐 대응** — Windows 는 국기 이모지 글꼴이 없어 🇰🇷 가 "KR" 로 보인다. 국기가 디자인의 중심이라 필수. 지원 안 되는 브라우저에서만 Twemoji 국기 글꼴(78KB, 자체 호스팅 `public/fonts`)을 주입 (`components/FlagPolyfill.tsx`)
2. **상세 액션 위치** — 05 문서는 하단 고정 바였지만, 탭 바의 🎙 와 겹치고 마이크가 두 개가 됐다 → 식이 배지 아래 인라인으로 이동. 이 🎙 는 "지금 보는 음식" 맥락으로 시트를 연다
3. **게스트 우선** — 로그인 없이 Passport·식이 조건을 브라우저에 저장(`lib/client/passport.ts`)하고, 질문 때 `guest` 프로필로 서버에 전달. 로그인 연동 후 `/api/me/*` 로 동기화
4. **미리보기 모드** — Supabase 키가 없으면 `lib/preview/` 샘플로 화면과 푸디가 같은 인터페이스(ContentSource·FoodisRepo)로 돈다. 샘플 문구는 **검수 전**이라 DB 에 넣지 않는다. 화면 상단에 노란 배너로 표시
5. **음성 fallback 체인** — 듣기: Web Speech → 녹음 후 `/api/foodi/stt` → 글 입력. 말하기: `/api/foodi/tts` → 브라우저 음성. 자막은 항상 표시
6. 탐험 기록 규칙 — 푸디 답의 카드에 나온 음식, 상세를 연 음식 = `explored`. 먹어봤어요/좋아요/저장은 사용자가 직접
7. **라디오는 읽기만 한다** — 대본을 LLM 으로 만들지 않고 검수된 필드(요약·유래·역사·문화)를 이어 붙인다(`lib/radio/script.ts`). 다음 이야기는 관계 그래프(역사적 연결 우선)를 따라가고, 끊기면 안 가본 나라로 "점프". 연결 문장도 DB 관계 설명을 그대로 읽어 "여러 설이 있어요" 같은 불확실성이 유지된다
8. **라디오 재생** — 세그먼트(≤560자)마다 서버 TTS, 다음 구간은 미리 받기, 8초 안에 안 오면 브라우저 음성(문장 단위). `<audio>` 하나를 재사용해 iOS 자동 재생 제한을 피하고, 잠금화면 조작(Media Session) 지원. 푸디가 듣거나 말하면 라디오는 잠시 멈춤. 재생한 에피소드는 탐험 기록
9. **My Table 배치** — 원형 링 대신 세로로 긴 식탁에 한상차림처럼 엇갈린 줄(열 수 × 엇갈림을 모두 시도해 접시가 가장 커지는 배치). 60개까지 겹침 없음을 테스트로 보장, 넘치면 최근 60개. 최근 5개만 차례로 "내려놓기"(260ms)
10. **My Table 이미지에는 사진을 그리지 않는다** — 위키미디어 사진은 CORS 헤더가 없어 canvas 가 오염된다. 국가색 접시 + 음식 모양 + 국기로 그리고, 화면의 사진 출처는 접시 카드에 표기
11. **지도는 서버가 그린다** — Natural Earth 1:110m(world-atlas) → d3-geo Equal Earth(중심 동경 11°, 사모아·통가가 오른쪽 끝에 모이게)로 경로를 서버에서 계산해 클라이언트에는 문자열만 보낸다. 이 해상도에 없는 나라(싱가포르·몰디브·몰타·사모아·통가)와 아주 작은 나라는 화면 크기가 고정된 점 마커로 탭 영역을 보장
12. **여정은 관계 그래프만 그린다** — 경로·설명 모두 DB 관계(`historical_link`·`regional_variant`)에서 오고 역사 문장을 새로 쓰지 않는다("여러 설이 있어요" 유지). 대권 호는 세계 지도와 같은 투영의 d3 `geoPath(LineString)`, 나라 위치는 가장 큰 땅덩이 중심(해외 영토 무시)
