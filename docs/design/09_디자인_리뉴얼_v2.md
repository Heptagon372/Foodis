# 🎨 디자인 리뉴얼 v2 — "Fresh Glass" (라이트 · 다크)

> v1(아이보리 + 민트 + 이모지 아이콘)을 레퍼런스 4종(식물 관리 앱 · Verdant 랜딩 · 온실 대시보드 · GreenBite 식단 앱)의 언어로 다시 입힌다.
> **기능·문구·흐름은 그대로, 옷만 바꾼다.** 주인공 색은 **흰색 · 초록 · 연두** — 검정은 쓰지 않는다. 라이트/다크 두 테마를 모두 지원하고, **새싹 토글**로 바꾼다.
> 기반 코드: `app/globals.css` · `components/ui.tsx` · `components/icons.tsx` · `components/ThemeToggle.tsx` · `lib/client/theme.ts` · `components/bits.tsx` · `FoodCard` · `DietBadge` · `VoiceButton` · `TabBar` · `AppFrame`.

## 2. 원칙

1. **흰색 · 초록 · 연두.** 주 버튼·활성 상태 = 초록(`brand`), 핵심 CTA·글로우·활성 탭 = 연두(`lime`), 면 = 흰 유리·흰 카드. 글자는 검정 대신 아주 진한 초록(`ink`). 새 hex 를 만들지 않는다. 예외: 식이 안전 의미색 `diet-*`, 콘텐츠인 국가 Accent(사진이 없을 때 카드 배경에만, 옅게).
2. **라이트/다크는 토큰으로.** `<html data-theme="light|dark">` 하나로 모든 토큰 값이 바뀐다. 화면 코드는 **토큰만** 쓴다 — `bg-white`·`text-black`·`bg-black/…`·고정 hex 를 면·글자에 직접 쓰면 다크에서 깨진다. (예외: 사진·숲 패널 위 `text-white`, 사진 그늘 `bg-shade/…`.) 꼭 필요할 때만 `dark:` 변형.
3. **아이콘은 무채색 라인 아이콘만** (lucide, `currentColor`). 아이콘 색은 `ink` · `ink-soft` · `muted` · `leaf` · `brand` · `on-brand` · `on-lime` · `lime` · `white`(숲 패널·사진 위) 중 하나. 색 있는 이모지 아이콘(🎙🎧📕🗺🏅❤️🔖📷🔥🎉 …)과 글자 기호 아이콘(▶ ⏸ ↻ ✕ ✓ › ← ⓘ ✦ ✎)은 UI 어디에도 남기지 않는다.
   - **예외(콘텐츠)**: 나라 국기 이모지(🇰🇷) · 음식 사진 · 소셜 로그인 공식 브랜드 표기.
4. **불편하지 않게.**
   - 터치 목표 40px 이상, 주요 동작 48px. 아이콘만 있는 버튼은 `IconButton`(44px) + `aria-label`.
   - 대비: 본문 `ink`, 보조 `ink-soft`, 3차 정보만 `muted`(13px 이상). 초록 위 글자는 `on-brand`, 연두 위 글자는 `on-lime`, 사진 위 글자는 `glass-dark` 칩 안에. **두 테마 모두에서** 읽혀야 한다.
   - 상태를 색만으로 말하지 않는다 — 아이콘 + 글자 함께.
   - 기존 `aria-*`·`role`·`sr-only`·키보드 동작·safe-area·`prefers-reduced-motion`·기능·이벤트 추적·문구 정보량은 유지.
5. **면.** `glass`(떠 있는 컨트롤·바탕 위 가벼운 카드) · `card`(읽을 게 많은 불투명 카드) · `meadow-panel`(밝은 연두 강조 면 — Passport 요약 등, 글자 ink) · `forest-panel`(진한 숲 초록 + 연두 글로우, 글자 흰색 — 화면당 많아야 하나: 홈 라디오 카드, 라디오 플레이어, 미니 플레이어). 사진 위 컨트롤 `glass-dark`.
6. **글꼴.** 제목·본문 Pretendard(`font-sans`, `font-display` 도 sans). 제목 `font-bold` + 토큰 자간(`text-h1`·`text-h2`·`text-title`). `font-serif`(Fraunces)는 워드마크와 **영문 한 단어 이탤릭 강조**에만. 한글 세리프 금지.
7. **모서리.** 큰 카드 `rounded-[28px]`, 카드 `rounded-3xl`, 카드 안 사진 칸 `rounded-[18px]`, 타일 `rounded-2xl`, 버튼·칩·탭 `rounded-full`.
8. **여백.** 화면 좌우 `px-5`, 섹션 사이 `space-y-8`, 카드 안 `p-4`~`p-5`.
9. **모션.** 기존 그대로(인트로 외 300ms 이하, 새싹 토글 예외). 상시 모션은 음성 버튼만.

## 4. 부품

- `btn(variant, size)` — `primary`(초록) · `lime`(연두+글로우, 화면의 핵심 CTA 하나) · `soft`(연두 옅은) · `glass` · `outline` · `ghost` · `on-dark`(숲 패널·사진 위). 크기 `sm` 40 · `md` 48 · `lg` 56px
- `chip(on)` — 토글 칩 40px, 켜짐 = 초록 채움
- `IconButton({icon, label, onClick, variant})` — 44px. `glass` · `outline` · `brand` · `lime` · `soft` · `ghost` · `on-dark`
- `BackLink({href, label, onPhoto?})` — 유리 알약 뒤로 가기 (사진 위면 `onPhoto`)
- `SegTabs` — 유리 트랙 + 초록 활성 알약, `role=tablist`
- `ProgressBar({value, max, label, onDark?})` — 초록 / 숲 패널 위 연두
- `IconTile({icon, tone, size})` — `soft`(연두 옅은+리프 아이콘) · `glass` · `brand` · `lime` · `outline` · `on-dark`
- `Eyebrow` — 11px 대문자 라벨(기본 leaf)
- `Section` · `MoreLink` · `FollowUpChip` · `Wordmark` · `PreviewBanner` · `SourceFooter` · `RelationRow`
- `Icon` / `ICONS` / `IconName` — 데이터(lib)는 아이콘 이름 문자열을 저장, 화면에서 `<Icon name=…>`
- `ThemeToggle` — **새싹 토글** 44px 유리 버튼. 누르면 새싹이 흙 속으로 쏙(다크), 다시 누르면 통통 돋아남(라이트). 홈·Passport 헤더 오른쪽에 둔다. `useTheme()` 으로 현재 테마
- `FoodCard` L/M/S · `DietBadge` · `VoiceButton`(초록 구슬 + 연두 맥박, 듣는 중엔 연두로 반전) · `TabBar`(떠 있는 유리 바, 68px + 아래 12px/안전 영역)

## 6. 화면 레시피

- **홈** — 헤더(워드마크 · Passport 알약 · 새싹 토글) → 2단 인사(`오늘은 어디로` ink-soft medium / **`떠나볼까요?`** ink bold) → 음성 구슬 + 글로 묻기 유리 알약 → 탐험 도구 4칸(`IconTile soft` + 라벨, 유리) → 오늘의 탐험(L 카드) → 라디오(`forest-panel`, 영문 이탤릭 "*Radio*", 연두 CTA) → 퀘스트 한 줄(아이콘 타일 + 진행 링) → 추천(M 카드 가로) → 최근 탐험(S 칩)
- **푸디 시트** — 바탕색 유리 시트(위 28px, 손잡이), 질문 말풍선 `bg-brand text-on-brand`(오른쪽), 자막 `text-subtitle`, 카드 가로 스냅, 후속 질문 `FollowUpChip`, 아래 입력줄 유리 알약 + 음성 구슬 md
- **음식 상세** — 사진 히어로(`BackLink onPhoto` + `IconButton`) → 겹쳐 올라오는 `canvas` 시트(28px) → 나라 링크 · 이름 `text-h1` · 영문명 → 액션(먹어봤어요·좋아요·저장 `chip(on)` + 묻기 `btn("primary")`) → `SegTabs`(기본/문화/식이/연결)
- **국가·재료** — 옅은 Accent 히어로 + `BackLink` → `ProgressBar` → 묻기 `btn("primary")` → M 카드 2열, 탐험 배지 유리 칩 + check
- **Passport** — 헤더(워드마크 · 지도 알약 · 새싹 토글) → `meadow-panel` 요약(큰 숫자 `text-display` 초록 + 대륙별 초록 진행 바) → My Table → 국기 그리드 → Food DNA(초록·연두 레이더) → 퀘스트 → 상태 목록 → 식이·알레르기(`chip`) → 설정 → 계정 → 하단 연두 CTA
- **라디오** — 채널 칩/타일(아이콘) → `forest-panel` 플레이어(사진, 연두 재생 버튼, 연두 진행) → 이어지는 이야기. 미니 플레이어는 탭 바 위 `forest-panel` 알약
- **지도·여정** — 라이트: 흰/연두 지도(바다 `sunken`, 미탐험 `surface`, 탐험 `brand`/`lime`), 다크: 같은 토큰이라 밤의 숲 지도. 대륙 칩 `chip`, 하단 카드 `glass`
- **My Table** — 식탁 일러스트는 콘텐츠라 유지(다크에서는 살짝 어둡게), 접시 위 음식 모양은 라인 아이콘, 범례·버튼은 v2 부품
- **로그인·온보딩·인트로** — 안개 바탕, 큰 2단 제목, 주 버튼 `btn("primary","lg")`, 선택 칩 `chip`
- **어드민** — 데스크톱 도구라 구조는 그대로, 토큰·아이콘만 v2 (토큰을 쓰면 다크도 저절로)
- **공유 이미지(canvas: share-card · table-card)** — 테마와 무관한 고정 라이트 팔레트(흰색·초록·연두), 이모지 아이콘 대신 선 도형
