- **자동(추천)** = 아무것도 안 고름 → 서버 기본 체인(`TTS_PROVIDER` 1순위, Google·OpenAI 는 env 음성 `GOOGLE_TTS_VOICE`·`OPENAI_TTS_VOICE`, 나머지는 제공자 기본 목소리: gemini-sulafat · eleven-talia-flash · clova-vara).

- 속도 등급은 측정 전 어림이다 (스트리밍 여부 + 공식 지연 수치). 실측은 08 문서 §2.

### 시도 순서 (`lib/voice/plan.ts`)

1. 고른 목소리 (그 제공자 키가 있을 때)
2. 기본 체인 — **다른 제공자만** (같은 제공자의 다른 음성은 장애·키 오류가 같아서 시간만 쓴다)
3. 모두 실패 → 503 → 브라우저 `speechSynthesis`
- 미리듣기(`exact:true`)는 1만. 다른 목소리로 대신 들려주면 미리듣기가 아니다.
- 응답 헤더: `X-TTS-Provider` · `X-TTS-Voice`(카탈로그 id) · `X-TTS-Mode`(stream · buffered · cache).

## 4. 라디오 2인 진행

| 구간 (lib/radio/script.ts) | 진행자 | 말투 (`lib/voice/styles.ts`) |
|---|---|---|
| summary · origin · history · culture | **A 이야기꾼** — 긴 이야기 | `story`: 차분하고 따뜻하게, 장면이 떠오르게 |
| open · bridge · close | **B 진행자** — 오프닝·다음 나라 소개·클로징 | `mc`: 밝고 경쾌하게 |

- 설정에서 둘을 고를 수 있다 (`radioHosts`). "자동" 칸은 역할 이름(`host-a`/`host-b`)으로 저장 → 서버가 준비된 제공자에서 고른다.
- 자동 짝 (`HOST_PREFS`, 앞에서부터 준비된 것): A = openai-cedar → eleven-darian-flash → google-chirp3-charon → clova-vian → google-neural2-c → gemini-sadaltager / B = openai-marin → eleven-talia-flash → google-chirp3-aoede → clova-vara → google-neural2-a → gemini-sulafat → google-wavenet-a. **성별·톤이 갈리게** 짰고, 키가 하나만 있어도 같은 제공자 안에서 짝이 된다 (테스트).
- 고른 진행자의 키가 없으면 그 역할의 자동 진행자로 (기본 체인으로 가면 두 진행자가 같은 목소리가 될 수 있다).
- 라디오 화면에 "🎙 진행 카론 · 아오이데" 처럼 작게 보이고, 지금 말하는 쪽이 조금 진하다. 브라우저 음성으로 떨어지면 대신 "브라우저 음성으로 재생 중".
- 말투 지시는 OpenAI(`instructions`) · Gemini(`style`)만 듣는다. 나머지는 목소리 자체로 갈린다.

## 5. 현지 발음 (`lib/voice/local.ts`)

음식 상세의 이름 옆 **🔈 현지 발음** → `name_local ?? name_en` 을 그 나라 말 목소리로.

1. 나라 → 언어: `COUNTRY_LANG` (시드 130개 나라 전부, 테스트). 공용어가 여럿이면 음식 이름이 주로 붙는 쪽 (캐나다 푸틴 → fr-CA, 남아공 보보티 → af-ZA, 벨기에 → fr-BE).
2. 언어 → 목소리 순서:
   1. **Google Chirp 3 HD 로케일 음성** `{로케일}-Chirp3-HD-Aoede` — 원어민 음성 (GA 로케일 51개: ja-JP · cmn-CN · it-IT · fr-FR · es-ES/es-US · de-DE · ar-XA · tr-TR · hi-IN · th-TH · vi-VN · id-ID · pt-BR · ru-RU …). 중남미 스페인어는 es-US, 캐나다 프랑스어는 fr-CA.
   2. **OpenAI marin** + `instructions` "그 나라 원어민처럼 이 음식 이름만"
   3. **ElevenLabs Talia (Flash v2.5)** + `language_code`
   4. **Gemini Sulafat (Flash-Lite)** + `style` — 암하라어(ET)·조지아어(GE)·크메르어(KH) 등 Chirp 에 없는 언어
3. 한국어 목소리로 대신 읽지 않는다 (의미가 없다). 서버에 맞는 목소리가 없으면 503 → 브라우저 `speechSynthesis` 를 그 언어(`u.lang = ja-JP`)로.
4. 어떤 제공자도 말하지 못하는 언어(라오어 LA · 몽골어 MN · 알바니아어 AL · 말라가시어 MG · 디베히어 MV · 투르크멘어 TM · 사모아어 WS)는 **영어 이름을 영어로** — 버튼이 "🔈 영어 발음" 으로 바뀐다.

## 6. 비용 · 예산

- 단가는 `lib/voice/pricing.ts` 한 곳 (출처·확인일 주석). 사용량(`api_usage`)은 **목록가로** 기록한다 — 월 무료 구간을 빼지 않아 일일 예산 가드가 보수적으로 동작한다. (전에는 Google 을 $0 으로 기록했다.)
- 분·토큰 단위 제공자는 한국어 말 속도 7자/초(라디오 자막과 같은 값)로 글자당 값으로 바꾼다: OpenAI ≈ $35.7, Gemini Flash ≈ $41.6, Flash-Lite ≈ $27.9 / 100만 자.
- **일일 예산 가드**: `/api/foodi/tts` 가 오늘 쓴 금액(`usageTodayUsd`, 30초 메모)이 `DAILY_BUDGET_USD` 이상이면 **캐시에 있는 음성만** 주고 새로 합성하지 않는다 → 503 `tts_budget` → 브라우저 음성.
- **캐시**: 서버 메모리 LRU 40개 · 15MB (하나 5MB 까지). 키 = 제공자 · 음성 · 모델 · 언어 · 말투 · 글자(sha256). 끝까지 받은 음성만 넣는다(중간에 끊긴 것 ✗). 캐시에서 준 음성은 사용량을 기록하지 않는다 (비용 0). 라디오 다시 듣기 · 미리듣기 · 데모 답이 주로 맞는다. 서버리스 인스턴스마다 따로다.
- 데모 규모 어림 (답 1개 ≈ 80자, 라디오 에피소드 1편 ≈ 1,500자): 1,000답 + 라디오 100편 ≈ 23만 자 → WaveNet $0.9 · Chirp 3 HD $6.9 · OpenAI $8.2 · Gemini Flash $9.6 · ElevenLabs Flash $9.2 · Multilingual $18.4 (무료 구간 전).

## 7. 클라이언트 재생

- MP3 스트림(OpenAI·ElevenLabs)은 `stream-audio.ts` 가 MediaSource 로 첫 조각부터 재생.
- Google·CLOVA(MP3 한 번에)·Gemini(WAV)는 `attachResponse` 가 `Content-Type` 을 보고 `MediaSource.isTypeSupported` 가 거절하면 blob 경로(다 받은 뒤 재생)로 간다 — 코드 변경 없이 맞게 동작한다. `audio/wav` 는 MSE 가 받지 않는다.
- Gemini 는 한 번에 다 만든다 → 긴 라디오 구간(560자 ≈ 80초)은 클라이언트 8초 제한을 넘길 수 있다 → 그 구간은 브라우저 음성. 그래서 자동 진행자 목록에서 Gemini 는 맨 뒤.
