# 15. 모임(카페형) · 음식 뉴스 · 지금 뜨는 음식 v1

> 14 문서(World Table)의 후속. 사용자 요청: "모임은 모임답게 — 모임을 만들고 그 안에서 글쓰기(카페처럼), 급상승이 딱 눈에 띄게, 함께 아래 음식 뉴스(자동 수집 · 카테고리 · 급상승)".

## 1. 커뮤니티 = 게시판 | 모임

| | 게시판 | 모임 |
|---|---|---|
| 무엇 | 누구나 쓰는 열린 글 (밥친구 + 주제 10개) | 사용자가 만든 모임, **가입한 사람만** 안에 글쓰기 |
| 주소 | `/community?c=<주제>` | `/community?tab=clubs` · `/community/clubs/:id` · `/community/clubs/new` |
| 글 | `club_id = null` | `club_id = 모임 id`, 카테고리는 모임 주제로 고정 |
| 일정 | 밥친구 글만 만날 시각·인원·참여 | 모임 글은 "정모 일정 넣기"를 켜면 시각·인원·참여 |

- 모임: 이름(2~30, 대소문자·공백 무시 중복 금지) · 주제(다이어트·할랄·채식·육식·콜라보·한식·중식·양식·일식·기타) · 소개 · 표지 사진. 만든 사람 = 운영자(자동 가입, 탈퇴 불가, 모임 삭제 가능 → 안의 글도 삭제).
- 읽기는 공개(카페의 전체 공개), 쓰기·가입은 운영에서 로그인 필요. 회원 수·글 수·마지막 글 시각은 트리거로 집계(0007).
- **급상승 모임**: 최근 48시간 (가입 1 + 글 2) 이 3 이상이고 이전 7일 평균(48시간 환산)의 2배+1 이상 (`lib/trends/rising.ts clubHeat`). 모임 목록 위 "급상승 모임" 줄 + 카드 🔥 배지.

## 2. 지금 뜨는 음식 (급상승 순위)

커뮤니티·뉴스 맨 위의 실시간 순위 패널(1위 크게 + 2~10위, NEW · ▲n · ×성장 배수).

```
뉴스 제목 ─┐                         ┌─ 최근 48h 언급 (뉴스 1 · 글 1.5+따봉)
커뮤니티 글 ┼─ extractFoodTerms ─ 언급 ┼─ 이전 7일 평균(48h 환산)
(게시판+모임)┘   (lib/trends/keywords) └─ 성장 = (최근+1)/(평균+1), 점수 = 최근 × √min(성장,9)
                                         순위 변동: 6시간 전 같은 계산과 비교 → NEW / ▲ / ▼
```

- **음식 키워드 추출**(규칙, 무료·재현 가능): ① DB 음식 이름(3글자 이상은 포함, 2글자는 낱말 그대로일 때만 → slug 연결) ② 유행 음식 사전(탕후루·요아정·두바이쫀득쿠키…) ③ 음식 꼬리말(…탕·…쿠키·…버거·…빵 등, 한 글자 꼬리말은 3글자 이상 낱말만). 조사는 떼어 봐서 맞을 때만 뗀다. 오탐 목록(목욕탕·비대면·전국 …)과 너무 넓은 말(음식·메뉴·디저트)은 제외.
- 실제 수집한 헤드라인 60개로 점검해 고친 오탐: 브리즈번→브리, 박미란→박미(2글자 DB 이름), "메뉴면"(어미 '면'), 페스티벌(DB 이름이지만 일반어).
- 2회 미만 언급은 순위에 넣지 않는다. 클릭: DB 음식 → 음식 상세, 아니면 → 그 키워드 뉴스. 1위 옆 마이크 → 푸디에게 묻기.

## 3. 음식 뉴스 (`/news`, 사이드바 '함께' 아래)

- 카테고리: **음식 뉴스**(신메뉴·외식·식품 트렌드) · **문화 뉴스**(식문화·축제·세계 음식). 카테고리별 검색어 목록(`lib/news/sources.ts NEWS_QUERIES`)으로 수집.
- **자동 수집**: 화면·순위 요청 때 마지막 수집이 30분 넘었으면 응답 뒤(`after()`)에 수집. 처음(빈 저장소)엔 최대 12초 기다렸다 보여 줌. 방문이 없어도 쌓으려면 스케줄러가 `GET /api/news/crawl` (`Authorization: Bearer $CRON_SECRET`) 을 30분마다.
- 수집 1회: 검색어별 호출(동시 3) → 제목 중복 제거(같은 보도자료 받아쓰기) → 14일 넘은 기사 버림 → 음식 키워드 추출 → 저장(url 중복 무시). 실패한 검색어는 건너뜀.
- 화면: 카테고리 탭(건수) · 뉴스 급상승 순위 · 급상승 키워드 칩(누르면 그 키워드 기사만) · 기사 카드(카테고리 · 🔥급상승 · 언론사 · 시간 · 제목→원문 · 키워드 칩).

### 수집원과 약관 (확인일 2026-10-02)

| 수집원 | 쓰는 때 | 근거 |
|---|---|---|
| 네이버 검색 API (뉴스) | `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET` 이 있으면 (운영 기본) | 공식 오픈 API, 하루 25,000회. 제목·링크·요약·날짜 표시 용도 |
| Google 뉴스 RSS | 키가 없고 **개발 서버일 때만** | 피드 본문에 "personal, non-commercial use" 로만 허용 → 운영 빌드에서는 수집하지 않고 키 안내를 보여 줌 |

기사 본문은 저장·표시하지 않는다. 제목·언론사·날짜(+네이버 요약 200자)만 보여 주고 원문 링크로 보낸다. 보관 60일 권장(`select purge_old_news();`).

## 4. 마이그레이션 · 설정

- `supabase/migrations/0007_clubs_news.sql`: `community_clubs` · `community_club_members` · `community_posts.club_id` · 카운터 트리거 · `news_articles`.
- 환경변수: `NAVER_CLIENT_ID` · `NAVER_CLIENT_SECRET` (네이버 개발자센터 → 애플리케이션 등록 → 사용 API '검색'), 선택 `CRON_SECRET`.
