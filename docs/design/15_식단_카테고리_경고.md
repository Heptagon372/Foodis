# 🚦 식단 카테고리 경고 v1

> 사용자가 고른 **종교 · 채식 단계 · 다이어트 · 건강 · 기타** 조건에 비춰, 맞지 않는 음식은 **빨간 라인**, 확인이 필요한 음식은 **노란 라인**으로 표시한다.
> 기존 식이 5종(03 문서)은 추천 필터, 이 문서는 그 위의 **경고 표시** 층이다.

## 1. 카테고리 (29개)

| 묶음 | 카테고리 | 위험(빨강) | 주의(노랑) |
|---|---|---|---|
| 종교·신념 | 할랄 · 코셔 · 힌두교 · 자이나교 · 불교 사찰식 | 돼지고기·술·피 / 돼지고기·갑각류·고기+유제품 / 소고기 / 고기·생선·달걀·꿀·뿌리채소 / 고기·생선·오신채 | 도축 방식(고기), 젤라틴, 종류 모를 고기 |
| 채식 단계 | 비건 · 락토 · 오보 · 락토-오보 · 페스코 · 폴로 · 플렉시테리언 | 각 단계에서 허용하지 않는 동물성 재료 | 고기 종류를 모를 때 |
| 다이어트 | 키토 · 저칼로리 · 팔레오 · 고단백 | 밥·면·빵·당분 / 튀김 / 곡물·콩·유제품·설탕 | 뿌리채소·콩, 가공육 |
| 건강·질환 | 글루텐 프리 · 유당불내증 · 당뇨 · 저염식 · 통풍 · 저포드맵 · 임신·수유 · 위장 보호 | 밀 / 유제품 / 당분 / 짠 양념·가공육 / 퓨린·술 / 오신채 / 날생선·날고기·술·수은 생선 / 매운맛 | 탄수화물·튀김, 해산물, 콩·밀, 카페인 |
| 기타 | 술 X · 카페인 X · 날것 X · 돼지고기 X · 소고기 X | 해당 재료 | 차(카페인 없는 차도 많음), 종류 모를 고기 |

비건·락토-오보·할랄·글루텐 프리·유당불내증은 기존 `diet` 키(추천 필터)와 같은 조건이라 고르면 추천에서도 빠진다. 나머지는 `guards`(이 기기에만 저장)로 경고만 한다.

## 2. 판정 규칙 (`lib/diet/guard.ts`)

1. **재료 신호(flag)** 를 모은다: 검수된 식이 값(`no` → 확실, `depends` → 아마도) · 알레르기 · 맛 태그 · 재료 이름 · 음식 이름 (확실) · 소개글 (아마도).
2. 신호는 위로 번진다: 돼지고기 → 고기 → 고기·생선 → 동물성 재료, 돼지고기·술·피 → 할랄 부적합.
3. 카테고리 판정: 위험 재료가 **확실**하면 위험, **아마도**이거나 주의 재료가 있으면 주의, 아니면 통과.
4. 근거가 하나도 없는 음식(검수 전 카탈로그)은 "정보 부족" — 경고 없음을 안전으로 오해하지 않게.
5. 이유는 가장 구체적인 재료로 말한다 ("고기·생선" 대신 "돼지고기").
6. 고기 종류가 확실하면 이름만 보고 짐작한 다른 종류는 버린다 (닭갈비 ≠ 소고기).

## 3. 화면

| 곳 | 표시 |
|---|---|
| 음식 카드 L·M | 위험 = 빨간 2px 라인 + 빨간 칩 "할랄 · 돼지고기 +2", 주의 = 노란 라인 + 노란 칩 |
| 음식 칩 S | 같은 라인 + ✕/⚠ 아이콘 |
| 상세 상단 | "내 식단에 맞지 않아요" 경고 띠 (조건별 이유) |
| 상세 '식이' 탭 | 고른 조건마다 위험 / 주의 / 걸리는 재료 없음 / 정보 부족 |
| 설정 · 온보딩 | 묶음별 카테고리 고르기 (온보딩은 "더 보기"로 접어 둔다) |

색만으로 말하지 않는다 — 라인 + 아이콘 + 글자 + 스크린리더 문구.

## 4. 한계

- 대표 조리법 기준이다. 식당마다 다르므로 "주문할 때 확인"을 항상 같이 말한다.
- 할랄·코셔 **인증**은 판정하지 않는다 (재료 기준 적합성만).
- 의료 조언이 아니다. 질환 카테고리는 흔히 권고되는 주의 재료만 알려준다.
