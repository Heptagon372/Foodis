# 16. 푸랜드 — 밥친구 찾기 v1

커뮤니티 탭 구성: **게시판 | 푸랜드 | 모임** (`/community?tab=buddy`).

## 흐름

1. **내 정보 + ON/OFF** — 원하는 음식 종류(채식·한식·중식·일식, 여러 개), 한마디(60자), 나이(만 19세 이상), 성별(남성·여성·비공개), 켜 둘 시간(1~8시간). 켜면 위치를 한 번 묻는다. 시간이 지나면 자동 OFF.
2. **지도** — 켠 사람끼리만 서로 보인다(반경 10km, 최대 50명). 내 위치는 화면이 열려 있는 동안 `watchPosition` 으로 따라간다(25m 이상 움직였거나 1분마다, 최소 15초 간격). 주변 목록은 10초마다 갱신.
   - 지도 키(`NEXT_PUBLIC_KAKAO_MAP_JS_KEY` / 네이버)가 있으면 실제 지도, 없으면 레이더(거리·방향만).
3. **점 누르기** → 그 사람 정보(음식·한마디·나이·성별·거리) → **대화하기** — 바로 1:1 대화 연결. 같은 두 사람은 진행 중인 대화 하나.
4. **대화방** `/community/buddy/:id` — 위에 상대 정보, 2.5초마다 새 메시지. **대화 종료**를 누르면 둘 다 더는 보낼 수 없다. 끝난 대화는 하루 동안 목록에 남는다.

## 안전·개인정보

- 남에게 보이는 좌표는 소수 셋째 자리(약 110m)로 반올림. 정확한 좌표는 서버에만.
- 끄면 바로 지도에서 사라진다. 꺼져 있으면 위치 갱신도 받지 않는다.
- 대화를 걸려면 나도 켜 둔 상태여야 한다 (상대도 내 정보를 보고 대화).
- 한마디에는 연락처·오픈채팅 아이디 금지(`ruleCheck`). 1:1 대화 본문은 막지 않는다.
- 운영은 로그인 사용자만. 미리보기는 게스트(anon id)도 가능.
- 보관: `purge_buddy()` — 끝난 지 7일 지난 대화, 7일 동안 안 켠 위치 삭제.
