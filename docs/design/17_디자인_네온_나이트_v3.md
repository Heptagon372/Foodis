# 🌌 디자인 v3 — "Neon Night" (다크 기본 · 네온 초록)

> 레퍼런스: 비행 시뮬레이터 대시보드("Hero Virtual Flight") — 거의 검정인 바탕, 어두운 유리 패널, 네온 초록 테두리·글로우, 상단 상태 알약, 왼쪽 사이드바, 하단 상태 스트립.
> v2(`09_디자인_리뉴얼_v2.md`)의 토큰 이름·부품·원칙은 그대로 두고 **다크 토큰 값과 앱 셸·홈 구도만** 바꾼다. 라이트 테마는 새싹 토글로 계속 쓸 수 있다.

## 1. 바뀐 것

| 영역 | v2 | v3 |
|---|---|---|
| 기본 테마 | 시스템 설정 | **다크** (새싹 토글로 고른 값은 계속 기억) |
| 다크 바탕 | 진한 숲 초록 `#0C140F` | 거의 검정 `#050806` + 옅은 초록 안개 |
| 다크 `brand` | 밝은 초록 + 어두운 글자 | 깊은 초록 `#138A3D` + **흰 글자** |
| 다크 `lime` | 연두 `#C8F06A` | **네온 초록 `#3DF57A`** (글로우·활성·진행) |
| 핵심 CTA `btn("lime")` | 연두 채움 | `cta` — 초록 그라데이션 + 네온 글로우, 흰 글자 |
| 켜진 메뉴·탭 | 연두 채움 | `neon` — 초록 테두리 + 안팎 글로우 |
| 데스크톱 셸 | 사이드바(워드마크·테마 포함) | **상단 상태 바**(`AppHeader`: 워드마크 · 탐험 국가 · 퀘스트 · 테마 · 계정) + 그 아래 떠 있는 사이드바 |
| 홈 | 인사 + 음성 구슬 + 바로 가기 | **히어로**(오늘의 탐험 사진) + **이번 주 챌린지** → **기능 타일 4칸** → **상태 스트립** + 푸디에게 묻기 |

## 2. 새 유틸리티 (`app/globals.css`)

- `panel` — 화면의 뼈대가 되는 큰 면(사이드바·히어로 옆 카드·타일·스트립). 위가 살짝 밝은 어두운 유리 + 옅은 초록 테두리
- `neon` — 지금 켜진 칸. `border` 클래스와 함께 쓴다 (`border neon`)
- `cta` — 핵심 CTA. 화면마다 한두 개 (홈: 히어로 '푸디에게 말하기', 스트립 '푸디에게 묻기', 챌린지 버튼)
- 테마별 변수: `--panel-bg` `--panel-border` `--neon-edge` `--neon-fill` `--neon-glow` `--cta-bg` `--cta-ink` `--cta-glow` `--forest-glow` `--meadow-glow` `--card-sheen`

## 3. 홈 구도 (레퍼런스 대응)

| 레퍼런스 | FOODIS |
|---|---|
| Explore. Learn. Master. 히어로 + Quick Start | 오늘의 탐험 사진 히어로 + "오늘은 어디로 떠나볼까요?" + 푸디에게 말하기 · 오늘의 탐험 칩 · 글로 묻기 |
| Daily Challenge | `QuestChallengeCard` — 이번 주 아직 안 끝난 퀘스트, 진행률, 보상, 챌린지 시작 |
| Aircraft · Scenarios · Training · Achievements | 세계 지도 · 음식 라디오(바로 재생) · World Table · Passport(최근 국기 배지) |
| Flight Zone · Wind · Altitude · GPS + Fly Now | 오늘의 나라 · 먹어본 음식 · 취향 반영 · 식단 조건 + 푸디에게 묻기 |

모바일은 같은 순서로 한 줄씩 쌓이고(타일·스트립은 2열), 하단 탭 바는 `panel` + 켜진 탭 `neon` + 가운데 `cta` 구슬.
