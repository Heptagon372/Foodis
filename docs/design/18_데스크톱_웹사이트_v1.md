> 레퍼런스: ① 진한 청록 판 + 파낸 모서리(노치)에 끼운 카드·화살표 UI (스타일) ② 랜딩 와이어프레임 Nav → Hero → Partners → Features → Why us → Review → FAQ → CTA → Footer (구조) ③ 프로토타입→디자인 예시 (히어로 아래 띠, 화살표 캐러셀, 첫 항목이 펼쳐진 FAQ).
> **lg(1024px) 이상에서만** 적용한다. 그 아래(모바일·세로 태블릿)는 v3(`17_디자인_네온_나이트_v3.md`) 화면 그대로.

## 1. 셸

| | 모바일 (< lg) | 데스크톱 (≥ lg) |
|---|---|---|
| 메뉴 | 하단 탭 바 `TabBar` | sticky 상단 알약 내비 `DesktopNav` — [워드마크] [진한 메뉴 알약 + 푸디에게 묻기] [새싹 테마] [계정 알약 ▾ (로그인·내 기록·설정)] |
| 바닥 | — | `SiteFooter` — 워드마크 + 묻기 입력 + 링크 열(`nav.ts FOOTER_COLUMNS`) + 진한 바닥 바와 가운데 둥근 홈 버튼 |

- 내비·푸터는 `AppFrame` 안에서 children 앞뒤로 그린다 (sticky 가 페이지 끝까지 붙게). `/admin`·`/onboarding`·`/intro`·`/login` 에는 없다.
- 높이 기준: `--desk-nav`(5rem) · `--desk-sticky`(내비 + 1rem). 다른 화면의 sticky 패널·`100dvh` 높이는 이 값을 뺀다. 앵커·키보드 포커스는 `html { scroll-padding-top: var(--desk-sticky) }`(lg)로 내비 아래에 멈춘다 — 화면마다 `lg:scroll-mt` 를 따로 주지 않는다 (겹치면 두 배).
- 메뉴 표는 여전히 `nav.ts` 하나: `DESK_PRIMARY`(탐험+함께) · `ACCOUNT_ITEMS`(내 기록 + 취향·식단) · `FOOTER_COLUMNS`.

## 2. 홈 = 랜딩 (`components/landing/`)

`HomeView` 는 컨트롤러 — 계산·부수효과(인트로·노출 기록·sessionStorage)는 한 곳에서, 화면은 `<main>` 하나 안에 모바일 트리(`lg:hidden`)와 `DesktopLanding`(`hidden lg:block`) 둘. 숨은 트리의 사진은 CSS 배경, 영상은 화면에 들어올 때 src 를 붙여 내려받지 않는다.

## 3. 새 유틸리티 (`app/globals.css`)

- `slab` — 평면 진한 판 (`--slab-bg`: 라이트 = forest, 다크 = 한 단계 밝은 숲색 — v3 다크 forest 는 바탕과 거의 같아서)
- `notch` + `notch-tl | notch-tr | notch-br`(모서리) + `notch-b`(아래 가장자리) — CSS mask 로 실제로 뚫는다. 크기는 `--nw/--nh`, `--bx/--bw/--bh`, 큰 홈은 `notch-lg`, 화살표 홈은 `dock-sm`. 내부 변수는 `@property inherits:false` 라 노치 안의 노치에 부모 구멍이 새지 않는다
- `tab-bottom` — 판 아래로 튀어나온 손잡이 · `desk-shadow` — 파낸 모양을 따라 떨어지는 그림자 (애니메이션·영상이 든 래퍼엔 쓰지 않는다)

**노치 규칙**: 홈에 앉는 버튼·알약은 마스크 요소의 *형제*(마스크는 자식·그림자·outline 을 자른다), 클릭할 수 있는 마스크 면은 *마스크 없는 링크 > 마스크 div* 로 (포커스 링이 잘리지 않게). 진한 판 위 포커스 링은 연두.

## 4. 정직성

- 숫자는 모두 런타임 값·코드 상수 (`app/page.tsx` 의 `SiteFacts`). 음식 수는 `countFoods()` — `listFoods` 는 PostgREST 상한 1,000행에서 잘린다.
- 후기·별점·파트너 로고·뉴스레터·SNS 는 넣지 않는다. 문구(`landing/copy.ts`)는 실제 동작과 맞춰 둔다 — 로그인이 필요한 기능(커뮤니티 글·모임·푸랜드·맛집 평점), 맛집탐방 위치(열 때 한 번 묻고 저장 안 함), 푸랜드 위치(켜 둔 동안 공유, 약 100m 로 흐림), 사진 출처(상세 화면).
