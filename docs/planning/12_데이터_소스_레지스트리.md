# 🗂️ 12 데이터 소스 레지스트리

> 업로드 문서 「음식·식문화 데이터 소스 정리」(2026-10-01)를 FOODIS 기준으로 판정한 결과. Supabase `data_sources` 테이블(`supabase/migrations/0002_data_sources.sql`)과 Notion 「데이터 소스 레지스트리」 DB에 같은 내용이 들어 있다.

## 판정 기준

- **DB 저장 가능**: CC0·공공데이터·공공누리 1유형처럼 자체 DB에 넣어도 되는 소스
- **근거·링크만**: 내용을 저장하지 않고 LLM 초안 근거나 링크로만 쓰는 소스 (위키백과, UNESCO, EnviDat(ODbL 전파 방지))
- **실시간 호출만**: 결과 캐싱·저장이 약관상 금지된 소스 (카카오·네이버·Google 장소 검색)
- **저장 금지**: 크롤링 금지·비상업·단기 캐싱 전용 소스
- DB의 `sources` 레코드는 반드시 `data_source_id`로 이 표와 연결되고, 실시간 전용·저장 금지 소스는 트리거가 기록을 막는다.

## 이번 반영으로 바뀐 점

- **카카오 로컬**: 결과 캐싱·저장 금지 확인 → 11 아키텍처 캐시 전략에서 캐시 제거, DB 트리거로 저장 차단
- **새로 채택**: 한국식품연구원 전통식품정보(한국 음식 문화 근거), UNESCO 인류무형문화유산(문화 이야기 공신력 근거)
- **EnviDat 국가 대표음식**: ODbL이라 DB에 섞지 않고 180개 음식 목록 검증 참고용으로만
- **Open Food Facts**: 가공식품 바코드 DB라 범위 밖 + ODbL 전파 위험으로 제외
- **영양(USDA·식약처·농진청)·레시피(식약처 COOKRCP01)·다국어(서울관광재단)**: Phase 2 확장으로 등록
