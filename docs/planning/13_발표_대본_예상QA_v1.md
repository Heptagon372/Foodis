## 2. 예상 Q&A 20

| # | 질문 | 답변 요지 |
|---|---|---|
| 1 | ChatGPT 에 묻는 것과 뭐가 다른가요? | ① 답의 사실(음식·식이·출처)은 검수된 DB 에서 나오고 서버가 검증한다 ② 관계 데이터로 다음 탐험이 이어진다 ③ 내 기록(Passport·취향)이 다음 추천을 바꾼다 — 범용 AI 는 세션이 끝나면 잊는다 |
| 2 | AI 가 틀린 할랄·알레르기 정보를 주면요? | AI 는 식이 여부를 말할 권한이 없다. 배지는 DB 컬럼에서 서버가 그린다. 근거가 엇갈리면 '확인 필요(⚠️)', 모르면 '❓'. 식이 조건이 있으면 맞지 않는 음식은 추천 후보에서 먼저 빠진다 |
| 3 | 음식 1만 개는 어떻게 모았고, 믿을 수 있나요? | Wikidata·위키백과를 근거로 정리하고 출처를 필드별로 저장했다. 공개는 verified 만, 어드민은 작성자와 검수자를 분리한다. 식이 규칙 검사로 모순(예: 고기 재료인데 비건 yes)을 걸러내고, 식이 정보에 신고가 3건 쌓이면 그 항목을 자동으로 '모름(❓)'으로 내린다 (DB 트리거) |
| 4 | 할루시네이션을 어떻게 측정했나요? | 30문항 점검 셋(없는 음식, 식이 함정, 엉뚱한 나라 등)을 만들어 자동 테스트로 돌린다 — 오프라인(가짜 LLM) 30/30. 실제 모델로 도는 측정(`eval:live`)은 발표 전 갱신 |
| 5 | 음성 인식이 틀리면요? | 인식된 글자를 화면에 보여 주고 고칠 수 있다. 브라우저 인식이 약하면 서버 STT 체인(여러 엔진 자동 대체), 사투리·외국어는 표준 한국어로 정규화. 텍스트 입력은 늘 열려 있다 |
| 6 | 답이 느리지 않나요? | 첫 문장부터 음성을 스트리밍 재생한다(다 받을 때까지 기다리지 않음). 목표는 첫 음성 p95 3초 이하 — 측정 도구(`bench:voice`, `/demo` 패널)로 잰다 |
| 7 | 외부 API 가 죽거나 비용이 터지면요? | 제공자 어댑터로 LLM·TTS·STT 를 자동 대체, 응답 캐시, 하루 예산 상한(기본 5달러). 다 실패해도 카드가 있는 템플릿 답은 나간다 — "Voice First, Card Always" |
| 8 | 왜 그 AI 모델을 썼나요? 바꿀 수 있나요? | 비용·속도·한국어 품질로 골랐고, 모델·제공자는 환경변수로 바꾼다(코드 수정 없음). 사용자가 설정에서 목소리·모델을 고를 수도 있다 |
| 9 | 식이 조건은 민감한 정보 아닌가요? | 로그인은 선택 — 기본은 이 브라우저에만 저장. 로그인하면 본인 계정에만(RLS). 추천 필터에만 쓰고 종교·건강을 추론하지 않는다. 로그아웃하면 기기에서 지우고, 탈퇴하면 계정째 삭제 |
| 10 | 로그인은 어떻게 하나요? | 카카오·Google·인스타그램(프로페셔널 계정)·이메일. 여러 방법을 한 계정에 연결할 수 있고, 게스트 때 모은 기록은 로그인하면 합쳐진다 |
| 11 | 추천은 어떻게 개인화되나요? | Food DNA — 좋아요·먹어봤어요·탐험·온보딩 취향에 가중치를 줘 맛·재료·나라 성향을 계산. 처음엔 나라별 대표 음식부터, 신호가 쌓이면 취향 순. 보고 지나친 추천은 다음에 덜 나온다 |
| 12 | 관계 데이터는 무엇이고 왜 중요한가요? | 같은 재료·비슷한 맛·같은 조리법·역사적 연결·지역 변이 5종, 13,464건. "검색이 아니라 탐험"을 만드는 핵심 — 상세 화면마다 다음 나라로 가는 길이 생긴다 |
| 13 | 맛집탐방의 위치 정보는요? | 카카오 로컬 검색으로 반경 안에서 그 음식을 파는 곳을 찾는다. 위치는 주변 검색에만 쓰고 저장하지 않는다. 위치 권한이 없으면 서울시청 기준 |
| 14 | 커뮤니티 악성 글·밥친구 안전은요? | 글은 규칙(연락처·외부 링크 도배 차단) + AI 사전 필터(혐오·괴롭힘·광고)를 거치고, 신고 3건이면 자동 숨김 + 어드민 신고 큐. 밥친구(푸랜드)는 만 19세 이상, 켠 사람끼리만 보이고 남에게 보이는 위치는 약 110m 로 반올림(정확한 좌표는 서버에만), 끄면 바로 사라진다 |
| 15 | 수익 모델은요? | 관광청·식품 브랜드의 국가 콘텐츠 파트너십, 식이 조건 사용자 대상 프리미엄(식당 메뉴 식이 확인), 맛집 제휴. 경진대회 범위 밖이지만 07 문서에 KPI·수익 구조 정리 |

## 3. 06 문서와 달라진 점

- 06 §4 의 "데이터 200개는 적지 않나요?" · "왜 지도가 없나요?" 는 더 이상 맞지 않는다 (지금 1만 개, 지도 있음) → 위 #3 · #12 · #19 로 대체
- 확장 로드맵(지도·라디오·월드 테이블)은 대부분 이미 만들었다 → 슬라이드 11 은 "만든 확장 + 다음 확장" 두 줄로
